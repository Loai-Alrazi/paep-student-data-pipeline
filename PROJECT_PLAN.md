# Project Overview

Multi-Source Student Data Pipeline is a group project for the PAEP Data Engineering course using CSV, REST API, and SQLite sources. The current stage establishes the project foundation only.

# Project Goal

Build a student data pipeline that follows: Extract → Validate → Clean → Integrate → Transform → Final Validation → Load.
