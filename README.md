# Multi-Source Student Data Pipeline

A group project for the PAEP Data Engineering course, designed to integrate student data from CSV files, a REST API, and SQLite.

The planned pipeline is:

Extract → Validate → Clean → Integrate → Transform → Final Validation → Load

This baseline contains only the project structure, Python placeholders, and initial team responsibilities. Extraction, validation, cleaning, integration, transformation, and loading will be implemented in later stages.
